A command-line application that analyses student academic performance using Python, NumPy, Pandas, Matplotlib and seaborn.
It generates a deliberately messy synthetic dataset, cleans it while logging every decision (155 records down to 139), calculates configurable weighted grades, analyses results by department and semester, and exports eight charts and CSV reports. 
The project is organised into 12 modules and covered by 69 automated unittest tests.
All data is synthetic, and the grading rules are examples, not an official policy.
